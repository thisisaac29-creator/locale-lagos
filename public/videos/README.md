# Video

- `hero.mp4` — muted H.264 loop for the home hero. Set `site.heroVideo.available = true` in `src/data/site.ts`.
- `tour.mp4` — walkthrough for the gallery video tile. Set `galleryVideo.available = true` in `src/data/gallery.ts`.

Both are optional. The site uses labelled image placeholders while they are absent. Keep files small (a few MB) and supply a poster frame for the hero.
